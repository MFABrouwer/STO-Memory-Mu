# Stores

Permanente referenties voor de inhoud van in-game stores. Wordt zelden bijgewerkt — alleen wanneer Cryptic items toevoegt of verwijdert, of wanneer ik iets koop.

## Files in deze folder

| File | Inhoud |
|------|--------|
| [`phoenix-store.md`](./phoenix-store.md) | Phoenix Prize Pack store, alle 4 tiers (Epic, UR, VR, Rare) |
| [`c-store.md`](./c-store.md) | Zen Store: Zen balance teller, wishlist, transaction log |
| [`fleet-stores.md`](./fleet-stores.md) | Spire, Embassy, Colony, Research store gear — Space en Ground secties |
| [`mudds-market.md`](./mudds-market.md) | Periodieke Mudd's Market deals (op datum) |
| [`lobi-store.md`](./lobi-store.md) | Lobi Crystal store (alleen items die ik wil) |

## Werkwijze

Per store: aparte "bezit" of "wishlist" kolom zodat in één oogopslag duidelijk is wat ik nog kan kopen vs. wat al af is.

## Quick reference — currencies

| Currency | Verkrijgbaar via | Beste besteding |
|----------|------------------|-----------------|
| Zen | Echt geld of dilithium-naar-Zen exchange | Ships, packs, services |
| Dilithium | Refining cap 8000/dag, dagelijkse missions | Phoenix Boxes, fleet projects, Zen exchange |
| Phoenix Tokens | Phoenix Boxes, Re-Engineering Beacons | Phoenix Universal Tech Upgrades |
| Lobi Crystals | Lockboxes, Phoenix Promotion events | Sparingly; specifieke items alleen |
| Fleet Credits | Fleet contributies | Fleet store gear |
| EC | Drops, exchange | Items van exchange, master keys, etc. |

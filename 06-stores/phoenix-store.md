## Token-grindplanning

Bronnen voor Phoenix Tokens:

- Phoenix Box uit dilithium store: kost dilithium per box, levert random token (vaak Common/Rare)
- Re-Engineering Beacon ruilen
- Periodic event reward tracks die tokens geven
- Phoenix Promotion events (random Cryptic announcements)
